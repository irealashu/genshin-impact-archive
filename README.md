# genshin-impact-archive

Genshin Impact Archive (XLSX)

This repository contains a spreadsheet archive of Genshin Impact data exported to an Excel workbook.

Contents

- `Genshin Archive.xlsx` — an Excel workbook with structured sheets for:
  - Characters
  - Weapons
  - Artifacts
  - Books
  - Regions

Data coverage: collected and exported up to version 7.0.

How to use

1. Download `Genshin Archive.xlsx` from this repository.
2. Open it with Microsoft Excel, LibreOffice Calc, or import it into Google Sheets.
3. Each sheet contains rows for individual items/entities and columns for attributes (e.g. names, stats, descriptions). Use filters or pivot tables to explore the data.
